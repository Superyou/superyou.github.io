Selected work

Research with systems impact

RISC-V · CFI · LLVM

Branch Landing

A section-aware fine-grained forward-edge control-flow integrity framework for RISC-V. The design uses BLD/BRL ISA extensions, landing-site validation, and Bloom-filter-based source authorization to protect indirect control transfers with low overhead.

Security · Coherence

Reversible Coherence Protocol

A low-overhead coherence-level mitigation for transient execution attacks. The work extends cache coherence mechanisms with undo, merge, and purge support to preserve security while allowing speculative execution.

Accelerators · BNN

Binarized Neural Network Acceleration

Early work on FPGA and accelerator implementation for binarized neural networks, including hardware/software interface design and VLSI-oriented accelerator exploration.
